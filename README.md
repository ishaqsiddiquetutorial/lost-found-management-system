# FindIt – Lost and Found Management System

FindIt is a full-stack web application designed to help communities report, search, and recover lost items easily.

## 🚀 Features
- *Report Lost/Found Items:* Users can submit item details along with photos.
- *Live Overview Dashboard:* Real-time statistics tracking total reports and recovered items.
- *Image Uploads:* Handled via custom backend routing.

## 🛠️ Tech Stack
- *Frontend:* HTML5, CSS3, JavaScript
- *Backend:* Python (server.py)
- *Data Storage:* JSON (data.json)
