# 🔍 Lost and Found Management System

A full-stack web application designed to connect people who have lost items with those who have found them.

## 🚀 Features
* **Report Lost Items:** Submit details, descriptions, and location information for misplaced belongings.
* **Report Found Items:** Post items found in public spaces to help reunite them with their owners.
* **Search & Filter:** Easily filter through reported listings to find matching items.
* **Responsive UI:** Clean, intuitive interface accessible across desktop and mobile devices.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Version Control:** Git, GitHub
